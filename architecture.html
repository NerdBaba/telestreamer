Data flow when Turbo goes live

  1. Detect — turbo_events polls the public preview and sees “Live stream started”. No login, no MTProto.
  2. Arbitrate — sources.resolve() returns chosen: turbosportslive.
  3. Start — reconcile() starts FFmpeg against the HF Turbo HLS URL.
  4. Open channel — TelegramPublisher gets RTMP credentials and creates the call only if none exists.
  5. Push — rtmp_sender streams the local playlist to Telegram. Bandwidth is served by Telegram.
  6. Watch — the Worker cron pings relay /healthz and HF /health.
  7. Stop — “Live stream finished” flips the signal; media stops and the call created here is discarded.
